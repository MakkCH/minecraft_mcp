JsMacros Reloaded 2.2.1 — compact signature index
Eight classes, checked against the 26.1 (26.1/26.1.1/26.1.2), 26.2 and 26.3 source profiles.
The listed outer-class public declarations match across those profiles.
Globals map to classes: Player → FPlayer, World → FWorld, Hud → FHud,
Client → FClient, Chat → FChat, KeyBind → FKeyBind, JsMacros → FJsMacros.
ServiceManager is also indexed. Search signatures with rg.
Helper methods such as getX(), getYaw() and addBox(), plus JavaWrapper, are outside
this index. Follow the return type into the versioned source or inspect the installed
JAR with javap (see mods.md). Source Javadocs describe semantics and threading.
Links below use the effective 26.3 sources. Other profile overrides are under:
https://github.com/grepsedawk/JsMacros/tree/v2.2.1/src/versions
